# KivyAPK

A project for building Kivy applications as APK files.

## Testing

This project includes unit tests to ensure code quality.

### Running Tests

To run the test suite:

```bash
python test_module_test.py
```

For verbose output:

```bash
python test_module_test.py -v
```

### Test Coverage

The test suite includes:
- Mathematical operations (add, subtract, multiply)
- String formatting and greeting functions
- Edge cases (zero, negative numbers, empty strings)

All tests use Python's built-in `unittest` framework.
